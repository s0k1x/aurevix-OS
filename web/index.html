Dos formas de instalar

  1. Launcher Installer — si ya tienes Windows 11: ejecútalo y se encarga de todo (Control Center, accesos directos y asistente de primer inicio).
  2. ISO Builder — para una instalación limpia: descargas la ISO oficial de Windows 11 desde Microsoft, el ISO Builder la convierte en una ISO de AUREVIX OS en tu propio equipo y la grabas en un USB (por ejemplo con Rufus).
¿Por qué no hay una ISO lista para descargar? La licencia de Windows no permite redistribuir Windows modificado. Por eso la ISO se construye en tu PC a partir de la oficial de Microsoft. Windows se activa con tu propia licencia: AUREVIX no incluye claves ni activadores.

Actualizaciones automáticas

Si ya tienes AUREVIX instalado, no necesitas volver aquí: cuando publicamos una versión nueva, aparece una pantalla de actualización en tu equipo. Los paquetes están firmados digitalmente y se verifican antes de instalarse; nunca se instala nada sin tu confirmación.
